### Zomato Restaurant Data Analysis

**Code:** [zomato-data-analysis](https://github.com/OK1414/zomato-data-analysis)

**Goal:** To analyze Zomato restaurant data and uncover insights 
about ratings, pricing, and cuisine trends across cities.

**Description:** The project involved loading a real Zomato dataset, 
cleaning and preprocessing raw data, performing full Exploratory 
Data Analysis (EDA), and creating visualizations to identify 
patterns in restaurant ratings, price ranges, and popular cuisines.

**Skills:** Data cleaning, EDA, data visualization, 
pattern recognition

**Technology:** Python, Pandas, Matplotlib, Seaborn, 
Jupyter Notebook

**Results:** Identified top-rated restaurant categories, 
price vs rating correlations, and most popular cuisines — 
providing actionable insights for business decisions.
